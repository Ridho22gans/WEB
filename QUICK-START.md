# 🚀 Quick Start Guide - Website MPK\n\n## Navigasi Cepat\n\n### 📍 Halaman Utama\n- **Beranda** (index.html) - Dashboard utama dengan statistik\n- **Profil** (profil.html) - Profil organisasi dan struktur\n- **Berita** (berita.html) - Daftar berita terbaru\n- **Detail Berita** (berita-detail.html) - Halaman detail setiap berita\n- **Agenda** (agenda.html) - Jadwal kegiatan MPK\n- **Forum** (diskusi.html) - Forum diskusi antar siswa\n- **Saran** (saran.html) - Kotak aspirasi dan saran\n- **Unduhan** (unduhan.html) - Download dokumen resmi\n- **Kontak** (kontak.html) - Informasi kontak MPK\n- **Admin** (admin.html) - Panel administrasi\n\n---\n\n## 🎮 Cara Menggunakan Fitur\n\n### 1. **Membaca Berita**\n```\n1. Klik menu \"Berita\" di navbar\n2. Pilih kategori filter (Semua, Kegiatan, Organisasi, Informasi)\n3. Klik \"Baca Selengkapnya\" untuk melihat detail\n4. Klik tombol \"Kembali\" untuk kembali ke daftar\n```\n\n### 2. **Forum Diskusi**\n```\n1. Klik menu \"Diskusi\"\n2. Isi form dengan nama, judul, dan isi diskusi\n3. Opsi: Pilih untuk mengirim sebagai \"Anonim\"\n4. Klik \"Posting Topik\"\n5. Topik Anda akan muncul di daftar diskusi\n```\n\n### 3. **Mengajukan Saran/Aspirasi**\n```\n1. Klik menu \"Saran\"\n2. Isi data: Nama (opsional), Kelas, Kategori, Isi\n3. Centang \"Kirim sebagai anonim\" jika ingin anonim\n4. Klik \"Kirim Saran\"\n5. Notifikasi akan muncul jika berhasil\n```\n\n### 4. **Mode Gelap/Terang**\n```\n1. Cari tombol toggle tema di navbar (sebelah hamburger menu)\n2. Klik untuk berganti tema\n3. Tema akan tersimpan otomatis\n```\n\n### 5. **Panel Admin** (Khusus Admin)\n```\n1. Buka halaman Admin\n2. Lihat statistik: Berita, Aspirasi, Diskusi\n3. Tambah berita baru:\n   - Isi judul, kategori, dan konten\n   - Klik \"Simpan Berita\"\n4. Hapus berita:\n   - Cari berita di tabel\n   - Klik tombol \"Hapus\"\n```\n\n---\n\n## 📱 Responsive Design\n\n### Desktop\n- Navbar penuh dengan semua menu\n- Layout 3-4 kolom untuk grid\n- Sidebar dapat ditampilkan\n\n### Tablet\n- Menu yang dapat di-collapse\n- Grid 2-3 kolom\n- Touch-friendly buttons\n\n### Mobile\n- Hamburger menu otomatis\n- Single column layout\n- Large touch targets\n- Swipe navigation\n\n---\n\n## 💾 Data Persistence\n\nSemua data yang Anda buat **otomatis tersimpan** di perangkat Anda:\n- Berita yang ditambahkan\n- Topik diskusi yang dibuat\n- Saran/aspirasi yang dikirim\n- Preferensi tema\n\n⚠️ **Catatan**: Data disimpan di browser lokal. Jika cache browser dihapus, data akan hilang.\n\n---\n\n## 🎨 Customization\n\n### Mengubah Warna\n1. Buka `css/style.css`\n2. Cari `:root` di awal file\n3. Ubah nilai `--primary`, `--secondary`, dll\n\n### Menambah Berita Default\n1. Buka `js/berita.js`\n2. Ubah `DEFAULT_BERITA` array\n3. Tambah object berita baru dengan format:\n```javascript\n{\n  id: '3',\n  title: 'Judul Berita',\n  category: 'Kegiatan',\n  date: '2026-08-13',\n  image: 'url-gambar',\n  content: 'Isi berita'\n}\n```\n\n### Menambah Menu Baru\n1. Tambah link di navbar (di semua HTML file)\n2. Buat halaman HTML baru\n3. Jangan lupa include `utils.js` dan `main.js`\n4. Update `main.js` untuk routing\n\n---\n\n## 🐛 Troubleshooting\n\n### Notifikasi Toast Tidak Muncul\n✓ Solusi: Buka DevTools (F12) → Console\n- Cek apakah ada error message\n- Pastikan utils.js dimuat\n\n### Berita Tidak Tampil\n✓ Solusi:\n1. Buka admin.html\n2. Tambahkan berita terlebih dahulu\n3. Kembali ke berita.html\n\n### Data Hilang Setelah Refresh\n✓ Solusi: Kemungkinan cache browser terhapus\n- Buka DevTools → Application → Local Storage\n- Cek apakah data masih ada\n\n### Form Tidak Berfungsi\n✓ Solusi:\n1. Buka DevTools → Console\n2. Cari error message\n3. Cek apakah semua field terisi\n4. Pastikan JavaScript tidak diblokir\n\n### Hamburger Menu Tidak Muncul di Mobile\n✓ Solusi: Refresh halaman atau clear browser cache\n\n---\n\n## ⌨️ Keyboard Shortcuts\n\n| Shortcut | Fungsi |\n|----------|--------|\n| F12 | Buka DevTools |\n| Ctrl + Shift + Delete | Buka Browser Settings |\n| Ctrl + L | Highlight URL bar |\n| Alt + ← | Kembali ke halaman sebelumnya |\n| Alt + → | Maju ke halaman berikutnya |\n\n---\n\n## 📞 Tips & Trik\n\n### 1. Export Data Aspirasi\n```\n1. Buka DevTools (F12)\n2. Buka Console\n3. Ketik: JSON.stringify(JSON.parse(localStorage.getItem('mpk_aspirasi')), null, 2)\n4. Copy hasil output\n5. Paste di text editor untuk simpan\n```\n\n### 2. Hapus Semua Data\n```\n1. DevTools → Console\n2. Ketik: localStorage.clear()\n3. Refresh halaman\nⓘ Semua data akan kembali ke default\n```\n\n### 3. Test Performa\n```\n1. DevTools → Performance tab\n2. Klik record\n3. Navigasi antar halaman\n4. Stop recording untuk lihat analisis\n```\n\n### 4. Debug Network\n```\n1. DevTools → Network tab\n2. Refresh halaman\n3. Cek apakah semua file JS dimuat (status 200)\n```\n\n---\n\n## 🎓 Untuk Developer\n\nJika Anda ingin memodifikasi atau develop lebih lanjut:\n\n### Struktur Folder\n```\nmpk-website/\n├── index.html\n├── berita.html\n├── diskusi.html\n├── saran.html\n├── admin.html\n├── ... (halaman lainnya)\n├── css/\n│   └── style.css\n├── js/\n│   ├── main.js\n│   ├── utils.js\n│   ├── berita.js\n│   ├── diskusi.js\n│   ├── saran.js\n│   └── admin.js\n├── assets/\n│   ├── images/\n│   ├── icons/\n│   └── documents/\n```\n\n### Console Commands untuk Testing\n```javascript\n// Get semua berita\nJSON.parse(localStorage.getItem('mpk_berita'))\n\n// Tambah berita manual\nvar berita = JSON.parse(localStorage.getItem('mpk_berita') || '[]');\nberita.push({id: '3', title: 'Test', category: 'Test', date: '2026-08-13', image: 'https://via.placeholder.com/600x400', content: 'Test content'});\nlocalStorage.setItem('mpk_berita', JSON.stringify(berita));\n\n// Test toast\nshowToast('Test notifikasi', 'success')\n\n// Check theme\ndocument.documentElement.getAttribute('data-theme')\n```\n\n---\n\n## 📚 Bacaan Lebih Lanjut\n\n- `SCRIPT-DOCUMENTATION.md` - Dokumentasi teknis lengkap\n- `IMPLEMENTATION-SUMMARY.md` - Ringkasan implementasi\n- `css/style.css` - Styling dan tema\n\n---\n\n**Selamat menggunakan Website MPK! 🎉**\n\nJika ada pertanyaan, silakan periksa dokumentasi atau hubungi tim development.\n
