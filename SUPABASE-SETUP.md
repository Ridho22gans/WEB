Pilih sign up dengan GitHub atau Email\n   - **Dengan GitHub** (Recommended):\n     - Click \"Continue with GitHub\"\n     - Authorize Supabase\n   - **Dengan Email**:\n     - Masukkan email\n     - Set password\n     - Verify email\n\n### Step 2: Create Organization\n\n1. Masukkan nama organization: **MPK SMKN 1 Bantul** (atau nama Anda)\n2. Klik \"Create organization\"\n\n### Step 3: Create Project\n\nKomponen penting:\n\n```\nProject Details:\n├── Project Name: mpk-website\n├── Database Password: [JANGAN LUPA PASSWORD INI!]\n├── Region: Asia (Singapore) - Pilih yang terdekat\n└── Pricing Plan: Free (cocok untuk development)\n```\n\n**Langkah:**\n1. Di dashboard, klik **\"New Project\"**\n2. Isi form:\n   - **Project Name**: `mpk-website`\n   - **Database Password**: `BuatPasswordKuat123!` (ingat password ini!)\n   - **Region**: `Asia (Singapore)` atau terdekat dengan Anda\n   - **Pricing Plan**: `Free` (gratis 500MB database)\n3. Klik **\"Create new project\"**\n\n**⏳ Tunggu 2-3 menit sampai project selesai setup.**\n\n### Step 4: Ambil API Keys\n\nSetelah project ready:\n\n1. Klik project name di sidebar\n2. Klik **\"Settings\"** (icon gear di bawah)\n3. Klik **\"API\"**\n4. Cari section **\"Project API keys\"**\n5. Copy dan simpan:\n\n```\n📋 SIMPAN DI TEMPAT AMAN:\n\n1. Project URL:\n   https://YOUR_PROJECT_ID.supabase.co\n   \n   Example: https://xyabc123def.supabase.co\n\n2. anon public key (BOLEH dibagikan):\n   eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\n   \n   Gunakan untuk client-side code\n\n3. service_role secret key (JANGAN dibagikan):\n   eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\n   \n   Gunakan hanya untuk backend/server\n```\n\n**💡 Tips**: Simpan di file lokal atau password manager. Jangan share di public!\n\n---\n\n## 🗄️ Setup Database\n\n### Step 1: Buka SQL Editor\n\n1. Di Supabase dashboard, klik **\"SQL Editor\"** (sidebar kiri)\n2. Klik **\"New Query\"**\n3. Hapus placeholder code\n\n### Step 2: Buat Table Berita\n\nCopy & paste SQL berikut:\n\n```sql\n-- Tabel Berita\nCREATE TABLE berita (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  title TEXT NOT NULL,\n  category TEXT NOT NULL DEFAULT 'Umum',\n  date DATE DEFAULT CURRENT_DATE,\n  image TEXT,\n  content TEXT NOT NULL,\n  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP\n);\n\n-- Enable Row Level Security\nALTER TABLE berita ENABLE ROW LEVEL SECURITY;\n\n-- Create Policy: Siapa saja bisa baca\nCREATE POLICY \"Anyone can read berita\"\nON berita\nFOR SELECT\nUSING (true);\n\n-- Create Policy: Siapa saja bisa insert (untuk demo)\nCREATE POLICY \"Anyone can insert berita\"\nON berita\nFOR INSERT\nWITH CHECK (true);\n```\n\nLalu klik **\"Run\"** (atau Ctrl+Enter)\n\n✅ Jika sukses, muncul notifikasi hijau.\n\n### Step 3: Buat Table Diskusi\n\nBuat Query baru, copy & paste:\n\n```sql\n-- Tabel Diskusi\nCREATE TABLE diskusi (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  author TEXT NOT NULL,\n  title TEXT NOT NULL,\n  content TEXT NOT NULL,\n  date DATE DEFAULT CURRENT_DATE,\n  comments INTEGER DEFAULT 0,\n  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP\n);\n\nALTER TABLE diskusi ENABLE ROW LEVEL SECURITY;\n\nCREATE POLICY \"Anyone can read diskusi\"\nON diskusi\nFOR SELECT\nUSING (true);\n\nCREATE POLICY \"Anyone can insert diskusi\"\nON diskusi\nFOR INSERT\nWITH CHECK (true);\n```\n\nKlik **\"Run\"**\n\n### Step 4: Buat Table Aspirasi (Saran)\n\nBuat Query baru:\n\n```sql\n-- Tabel Aspirasi/Saran\nCREATE TABLE aspirasi (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  nama TEXT NOT NULL,\n  kelas TEXT NOT NULL,\n  kategori TEXT NOT NULL DEFAULT 'Saran',\n  isi TEXT NOT NULL,\n  date DATE DEFAULT CURRENT_DATE,\n  status TEXT DEFAULT 'pending',\n  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP\n);\n\nALTER TABLE aspirasi ENABLE ROW LEVEL SECURITY;\n\nCREATE POLICY \"Anyone can read aspirasi\"\nON aspirasi\nFOR SELECT\nUSING (true);\n\nCREATE POLICY \"Anyone can insert aspirasi\"\nON aspirasi\nFOR INSERT\nWITH CHECK (true);\n```\n\nKlik **\"Run\"**\n\n### Step 5: Verifikasi Tabel\n\n1. Klik **\"Table Editor\"** (sidebar kiri)\n2. Lihat daftar table:\n   - ✅ berita\n   - ✅ diskusi\n   - ✅ aspirasi\n\n---\n\n## 🔒 Konfigurasi Security\n\n### Row Level Security (RLS) - Sudah dilakukan di atas\n\n✅ Semua table sudah punya RLS enabled\n\n### CORS Configuration\n\nSupabase sudah auto-configure CORS untuk website hosting. Jika pakai custom domain:\n\n1. Settings → API → CORS\n2. Tambah domain Anda\n3. Contoh: `https://mpk-website.pages.dev`\n\n### API Rate Limiting\n\nFree plan: 50 request/second (cukup untuk development)\n\n---\n\n## 📊 Insert Data Sample\n\n### Buat Query Insert Berita\n\n```sql\n-- Insert Sample Data Berita\nINSERT INTO berita (title, category, date, image, content)\nVALUES\n  (\n    'Pelaksanaan Pemilos SMK Negeri 1 Bantul 2026',\n    'Kegiatan',\n    '2026-08-10',\n    'https://via.placeholder.com/600x400',\n    'Pemilihan Ketua OSIS dan Ketua MPK berlangsung secara tertib dan demokratis dengan e-voting.'\n  ),\n  (\n    'Rapat Kerja & Sidang Pleno MPK',\n    'Organisasi',\n    '2026-07-25',\n    'https://via.placeholder.com/600x400',\n    'Pembahasan Anggaran Dasar / Anggaran Rumah Tangga serta pengesahan program kerja setahun.'\n  ),\n  (\n    'Forum Aspirasi Siswa',\n    'Informasi',\n    '2026-08-01',\n    'https://via.placeholder.com/600x400',\n    'Mekanisme pengumpulan aspirasi dari seluruh kelas dan pembahasan tindak lanjutnya.'\n  );\n```\n\nKlik **\"Run\"**\n\n### Verifikasi Data\n\n1. Buka js/supabase-config.js\n2. Check apakah SUPABASE_URL dan SUPABASE_ANON_KEY sudah benar\n3. Copy dari Supabase dashboard → Settings → API\n4. Jangan lupa replace `YOUR_PROJECT_ID` dengan actual ID\n\n### Problem 3: \"CORS error\"\n\n✅ Solusi:\n1. Supabase CORS sudah auto-enabled\n2. Jika pakai custom domain, add ke CORS list di Settings → API\n3. Cek console untuk full error message\n\n### Problem 4: \"RLS policy violation\"\n\n✅ Solusi:\n1. Check apakah RLS policy sudah create dengan benar\n2. Buka SQL Editor\n3. Run query untuk check existing policies:\n   ```sql\n   SELECT * FROM pg_policies WHERE tablename = 'berita';\n   ```\n4. Jika ada error, drop dan recreate:\n   ```sql\n   DROP POLICY IF EXISTS \"Anyone can read berita\" ON berita;\n   DROP POLICY IF EXISTS \"Anyone can insert berita\" ON berita;\n   ```\n\n### Problem 5: \"Table not found\"\n\n✅ Solusi:\n1. Buka Table Editor\n2. Cek apakah table berita sudah ada\n3. Jika tidak, jalankan CREATE TABLE query lagi\n4. Check di public schema (bukan private)\n\n---\n\n## 📱 Testing di Different Devices\n\n### Desktop (Chrome DevTools)\n```\n1. Buka F12\n2. Console tab\n3.
